# Vendored fonts

Latin-subset WOFF2 files from [Fontsource](https://fontsource.org) 5.3.0, loaded with `next/font/local`
in `app/layout.tsx`. Vendoring keeps builds (Docker, Vercel, CI) independent of Google Fonts.

| Family | Weights | License |
|---|---|---|
| IBM Plex Sans | 400, 500, 600 | SIL OFL 1.1 (`OFL-IBM-Plex-Sans.txt`) |
| Bricolage Grotesque | 500, 600 | SIL OFL 1.1 (`OFL-Bricolage-Grotesque.txt`) |
